================================================================================
                    PORTABLE AI - QUICK START
================================================================================

OPTION 1: START THE APPLICATION
================================================================================

WINDOWS:
  Run: launcher/windows/start.bat

LINUX:
  Run: launcher/linux/start.sh (first run: chmod +x start.sh)

macOS:
  Run: launcher/macos/start.command

The application will:
  1. Start the llama.cpp server with the local AI model
  2. Automatically open the Llama UI in your browser
  3. Access the UI at: http://127.0.0.1:8080

Keep the terminal window open while using the app.
Press Ctrl+C to stop the server.

================================================================================

OPTION 2: FIRST-TIME SETUP (Install models, etc)
================================================================================

WINDOWS:
  Run: installer/install.bat

LINUX/macOS:
  Run: installer/install.sh (Linux)

This will:
  1. Check your system requirements
  2. Download the recommended model (optional)
  3. Create required directories
  4. Configure the application

================================================================================

WEB INTERFACE
================================================================================

The Llama UI is automatically opened when you start the application.

If it doesn't open automatically, access it at:
  http://127.0.0.1:8080

This is the built-in llama.cpp web interface with chat functionality.

Both UIs share the SAME running model - no duplicate loading.

================================================================================

TIPS
================================================================================

- Keep the terminal open while using PortableAI
- Press Ctrl+C in the terminal to stop the application
- All data stays on the USB drive (portable)
- Works offline once started
- No installation needed on the host computer

================================================================================

TROUBLESHOOTING
================================================================================

Q: Python not found?
A: Install Python 3 from python.org or use your system package manager

Q: Model loading slowly?
A: First load takes longer as the model downloads. Subsequent starts are faster.

Q: Port already in use?
A: Edit .env file and change PORT or LLAMA_PORT to unused ports

For more info, see README.md

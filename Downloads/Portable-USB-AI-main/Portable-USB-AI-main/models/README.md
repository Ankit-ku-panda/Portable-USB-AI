# Installed Models for PortableAI
# Auto-updated by the system

Installed Models:
- Qwen3-4B-Q4_K_M.gguf (4B, 4-bit quantized, Lightweight & Fast)

To add more models:
1. Windows: Run install.bat and select option 2 or 3
2. Linux/macOS: Run install.sh and select option 2 or 3
3. Or manually download a GGUF model to the models/ folder

Recommended Model Sources:
- HuggingFace: https://huggingface.co/models?library=gguf
- Ollama: https://ollama.ai/library
- LM Studio: https://lmstudio.ai/

Model Format Required:
- Must be in GGUF format (.gguf extension)
- Recommended quantization: Q4_K_M (good quality/speed balance)
- Size depends on hardware (4GB RAM min for 7B models)
